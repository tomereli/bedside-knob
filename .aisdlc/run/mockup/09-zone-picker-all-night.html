One rule, said in both places it matters

The ALL entry carries exactly the sub-line and crescent the DIM card carries, for exactly the same reason: choosing ALL at 3am and then finding two strips frozen is the same surprise, arriving one screen earlier.

So on this page ALL does not show a percentage. It shows the set it will actually move. By day the same entry reads ALL 4 STRIPS and the crescent is gone.

The four named zones below it show a level, because a named zone is dimmed alone and the night rule does not narrow it.

Under an unknown clock — the first seconds after boot — this is what ALL looks like, because an unknown clock is treated as night. It is not a separate state and it does not announce itself; it just behaves safely and corrects when the time arrives.
