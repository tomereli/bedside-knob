Three faces that should not look alike

Why brightness alone cannot carry it

A two-tone ring works when both tones are on screen — the eye reads the bright one as a fraction of the dim one and gets a value for free. Remove the bright one and the reading collapses: a single ring of a single brightness has nothing to be a fraction of, so the eye reads what is there, which is a complete ring at the card's radius in the card's colour. The failure is not that #16324A is too bright. It is that it is alone.
